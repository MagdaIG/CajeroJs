# CajeroJs

ATM simulator built with JavaScript: balance, deposits and withdrawals.

## Tech Stack

JavaScript (ES6+), HTML5 and CSS3

## Getting Started

```bash
git clone https://github.com/MagdaIG/CajeroJs.git
cd CajeroJs
Open index.html in your browser
```
